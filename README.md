# Morphism-shell
A dynamic and fluid quickshell interface inspired by Material Design

## Images:
(WIP)

## Features:
A morphing dynamic island with:
- Time
- Expanded time (wip but will expand into a calendar and timer section once done)
- Notification
- Expanded notification

## Installation:
Dependencies:
- Quickshell

To install, clone the repository:
````git clone https://github.com/roccoflac/morphism-shell````\
then move the contents of the cloned folder to $HOME/.config/quickshell
