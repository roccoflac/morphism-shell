# Morphism-shell
A dynamic and fluid quickshell configuration inspired by Material Design

## Installation:
Dependencies:
- Quickshell
- materialyoucolor
- pillow

To install, clone the repository:
````git clone https://github.com/roccoflac/morphism-shell````\
then move the contents of the cloned folder to $HOME/.config/quickshell

## Theming:
Colours are generated by `morphism-gen`, a standalone Material You theme
generator (like Matugen/Wallust) that reproduces caelestia's palette pipeline
exactly. It renders templates, so the same tool can also theme other
applications. It lives outside this repo, at `~/projects/morphism-gen`.

On this NixOS setup it is installed declaratively via home-manager (see that
project's `default.nix`), which puts `morphism-gen` on `PATH`. To regenerate the
palette:

````sh
morphism-gen ~/Pictures/wallpaper.jpg
````

This regenerates `services/ThemeService.qml`. See
`~/projects/morphism-gen/README.md` for configuration and the template token
reference.
